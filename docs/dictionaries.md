# Словари и скоринг

## Данные

`data/dict/` содержит топ-50k FrequencyWords для `ru` и `en` (OpenSubtitles2018).
Лицензия данных — CC BY-SA 4.0, код — MIT; атрибуция и хэши в
[`data/dict/README.md`](../data/dict/README.md). Данные отделены от
MIT/Apache-кода, как требует ADR-015.

## Сборка

`crates/layoutpilot-dict/build.rs` при сборке:

1. читает `ru_50k.txt` и `en_50k.txt`;
2. оставляет только алфавитные слова, приводит к нижнему регистру,
   дедуплицирует и сортирует;
3. пишет FST-словарь `word → frequency` в `OUT_DIR`;
4. считает char-биграммы с маркерами начала/конца слова и генерирует
   компактный Rust-массив `(char, char, count)`;
5. встраивает FST через `include_bytes!`, а биграммы — через `include!`.

FST занимают ~0,9 МБ на обе локали, таблица биграмм — ~60 КБ исходника.
Сборка не требует `xkbcommon` или сети: данные лежат в репозитории.

## Скоринг

Для слова:

```
score = dict_weight * log P_dict(word)
      + ngram_weight * average(log P_bigram)
      + user_weight * log(1 + user_count)
```

- `P_dict` — частота слова / сумма частот; для неизвестного слова — штраф
  `0.5 / total`.
- `P_bigram` — сглаженная вероятность `(count + 1) / (total + distinct)`,
  усреднённая по всем биграммам слова, включая границы.
- `user_count` — подтверждения пользователя (`learn`/`unlearn`).

Вероятность:

```
p = sigmoid((score(candidate) - score(typed) - known_bias) / temperature)
```

`known_bias` вычитается, если исходное слово само есть в словаре: слова,
валидные в обоих языках, не исправляются без сильного перевеса (TZ §9.2).
Если кандидата нет в словаре, `p = 0`; это консервативно и предотвращает
автокоррекцию в незнакомые слова.

## Замеры

`cargo run -p layoutpilot-dict --example calibrate -- 50000` на топ-50k слов
длиной ≥ 3 (синтетический корпус «правильно → неправильная раскладка»):

| Язык | False positives (p ≥ 0.97) | True positives |
|---|---|---|
| en | 4 / 46 507 (0.009%) | 99.84% |
| ru | 0 / 48 829 (0.000%) | 99.82% |

Это не финальная калибровка: корпус синтетический, а порог и веса нужно
проверить на реальном корпусе с согласия пользователей (этап 3). Но запас по
FP относительно цели ≤ 0.3% большой.

## Упаковка

Для MVP словари и детектор живут в одном пакете `layoutpilot-dict`
(`publish = false`) с лицензией `(MIT OR Apache-2.0) AND CC-BY-SA-4.0`.
Перед публикацией данные можно разнести на отдельные пакеты
`layoutpilot-dict-ru` / `layoutpilot-dict-en`, как и предполагает ADR-015;
код детектора при этом остаётся MIT/Apache.

## Ограничения

- Словари — топ-50k; редкие и профессиональные слова считаются неизвестными.
- Нет word-bigram контекста и layout prior — поля `context_bonus` и
  `layout_prior` пока нулевые.
- Нет морфологии: словоформы, которых нет в списке, не узнаются.
- Калибровка температуры и `known_bias` предварительная.
